# Innovation Lab Monorepo

This monorepo contains the following applications for the TIL Hackathon:

- **Mobile App (Flutter)**: Located in `apps/mobile-app` (from `https://github.com/adr1el-m/til-hackathon`)
- **Sarai Sulong (Price Check and Sub)**: Located in `apps/sarai-sulong` (from `https://github.com/kuya-carlo/til-hackathon`)
- **Tanggol Saka (UI for Land Check)**: Located in `apps/tanggol-saka` (from `https://github.com/kuya-carlo/tanggol-saka`)
- **USSD Blaster UI**: Located in `apps/ussd-blaster` (from `https://github.com/kuya-carlo/blaster`)
