# Tanggol-Saka Web UI

## Tungkol Dito
Ang proyektong ito ay ang Web UI para sa **Tanggol-Saka**, isang desentralisadong socio-technical na sistema (TAO) na naglalayong tulay ang agwat sa impormasyon para sa mga katutubong magsasaka gamit ang offline at teknolohiyang nakasentro sa tao. Ang web interface na ito ay nagsisilbing bahagi ng aming solusyon para sa patunay ng pag-aari at pag-okupa sa lupa.

## Mga Tampok
- **Mapa ng Lupain**: Subaybayan at biswal na makita ang lokasyon at sukat ng lupain.
- **Talaan ng Ebidensya**: I-verify at itago sa ledger ang mga patunay ng pag-okupa (USSD logs, atbp.).
- **Opisyal na Katibayan ng Lupain**: Makabuo ng digital na sertipiko ng pagsasaka at pag-okupa na maaaring ma-download bilang PDF.

## Pag-setup
1. I-install ang mga dependencies:
   ```bash
   npm install
   # o
   pnpm install
   ```
2. Patakbuhin ang development server:
   ```bash
   npm run build
   # o
   npm run dev
   ```

Tinitiyak ng sistemang ito ang kalidad at pagiging desentralisado, lalo na para sa mga magsasakang Pilipino. Magsasaka-una, Tagalog-una!
